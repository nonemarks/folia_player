本模块由三个独立且无相互依赖的 CJS 工厂文件组成，均通过 `createXxxApi({...})` 工厂函数接收注入的依赖（store、safeStorage、getMainWindow、端口等），便于测试与组合。
- `kugouApiBridge.cjs`：维护一个 `OPERATION_MODULES` 映射表将高层操作名路由到 `kugoumusicapi` 的具体方法；通过 `createSessionPersistence` 使用 Electron `safeStorage` 以 V2 envelope（含 version/cookies）加密持久化 Cookie，并兼容旧版明文 session；自动注入 device cookies（guid/mid/mac/webgl）、登录态合并、渲染侧敏感字段清洗（token/dfid/cookie），并在收到 20028 时触发设备重注册重试。
- `lyricApi.cjs`：基于 Node `http` 在 `127.0.0.1:{port}/v1/lyric` 提供只读 JSON 接口，仅返回经 `sanitizeLyricData` 裁剪后的歌词快照（lines/words/backgroundVocals/translation/romanization），通过 `webContents.send('lyric-api-status-changed')` 向渲染进程广播启用状态。
- `stageApi.cjs`：实现完整的 Stage 模式服务器，HTTP 路由覆盖 `/stage/media/current/*`、`/stage/media/session/*`、`/stage/player/ws` 等，使用 Busboy 解析 multipart 上传、`ws` 库提供 WebSocket 播放器状态推送；所有外部请求通过 Bearer token（可配置存储）鉴权，输入数据经大量 normalize 函数（数字/整数/上下文/队列窗口）后写入内部 snapshot，并通过 diff 机制（queue revision/hash）向客户端增量推送；会话资产按 `STAGE_SESSION_RETENTION_LIMIT` 限制保留在 `app.getPath('userData')/stage/sessions` 目录中。

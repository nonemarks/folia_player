- 所有对外能力通过 `createXxxApi({ ... })` 工厂函数暴露，依赖（store、safeStorage、getMainWindow、端口、回调）以参数注入而非全局单例。
- 对外部输入统一先归一化再处理，使用 `normalizeStage*` / `copyText` / `copyTime` 等纯函数对字符串、数字、布尔值做安全转换并赋予默认值。
- HTTP 响应统一通过 `sendJson`/`sendBinary`/`sendFile` 辅助函数设置 `Access-Control-Allow-Origin: *`、`Content-Type`、`Content-Length` 等标准 CORS 头。
- 错误采用自定义类（如 `StageApiError`）携带 `statusCode`、`code`、`details` 三元组，便于上层统一序列化。
- 敏感数据（酷狗 token/dfid/cookie、Stage bearer token）仅在内存或经 safeStorage 加密后落盘，渲染侧返回体通过 `sanitizeRendererBody` 显式剔除密钥字段。
- 跨进程通知统一通过 `mainWindow.webContents.send(channel, payload)` 广播，payload 常包裹 `withStageInputMetadata` / `withStagePlayerInsideOutMetadata` 等元数据标记来源与方向。

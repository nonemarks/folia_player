本模块由一组职责单一、无相互依赖的 CJS 工厂/工具文件组成，全部在 Electron main 进程中加载，通过 `module.exports` 暴露函数供上层 main.cjs 编排：
- 第三方 API 启动：`neteaseApiStartup.cjs` 提供带指数退避+抖动的 `retryStartupOperation`，封装网易 xeapi 公钥刷新与匿名 token 获取；`qqApiStartup.cjs` 通过动态 `require('@yakult-green-tea/qq-music-api')` 启动其内置 HTTP 服务器，使用 `waitUntilListening` 等待端口绑定并隔离 `PORT`/`NODE_ENV` 等环境变量。
- 认证持久化：`qqAuthSessionRepository.cjs` 基于 `electron-store` + `safeStorage` 以版本信封（`ENVELOPE_VERSION=1`）加密保存 QQ 音乐服务端会话，Linux 下拒绝 `basic_text` 明文后端。
- 更新通道：`updateChannels.cjs` 将用户可见频道映射到 electron-updater 的 channel（realeco/beta/latest、limo/beta、cielo/alpha），并通过 rolling release tag 配置 generic provider。
- 资源与缓存：`localCoverAssets.cjs` 实现内容寻址（`sha256:...`）的封面存储，注册 `folia-cover://asset/<id>` 协议处理器，按 `size=512|1024` 懒生成缩略图并以临时文件+rename 原子写入；`audioCachePrune.cjs` 按 `usedAt`（mtime）LRU 选择淘汰条目。
- 系统交互：`voiceInputPause.cjs` 轮询 Windows 注册表 `ConsentStore\microphone`，用 START/STOP 样本计数防抖后通过 IPC 通知渲染器自动暂停；`displaySleepBlocker.cjs` 包装 `powerSaveBlocker` 实现幂等的显示休眠阻止。
- 播放交接：`windowPlaybackHandoff.cjs` 提供 TTL 过期的一次性播放状态交接，可选 `electron-store` 持久化以跨进程重启恢复。
- Whisper 对齐：`whisperAlign.cjs` 管理 whisper.cpp CLI 与 ffmpeg 子进程，支持模型下载（含 hf-mirror 镜像）、WAV 转换、多格式输出解析、作业取消与进度回调，所有 I/O 均通过 `child_process.spawn` 与 `fs` 完成。
依赖方向单向向外：各文件仅依赖 Node/Electron 内置模块或外部包，彼此之间不互相 require，由调用方组合。

- 每个模组以独立子目录组织，清单文件统一命名为 `mod.json`，入口统一为 `index.cjs`，并在其中导出 `module.exports = function activate(api) { ... }` 形式的激活函数。
- 模组通过 `mod.json` 的 `permissions` 数组显式声明所需能力（如 `render.export`、`filesystem.data`、`runtime.playback`、`visualizer.register`），未声明的 API 调用在调用点被拒绝。
- 需要跨进程能力的模组使用 `api.commands.register` 注册命令，命令参数通过表单自动渲染并经 IPC 回主进程执行，权限在加载器侧校验。
- 贡献全屏歌词动画的模组在 `mod.json` 中声明 `visualizers` 数组，将浏览器 ESM 模块（`.mjs`）通过 `folia-mod://` 协议交由渲染端加载，并以 `mod:<modId>:<id>` 形式命名避免覆盖内置模式。
- 所有异步资源（定时器、监听器、子进程、离屏窗口）均在 `api.lifecycle.onDeactivate` 注册的清理回调中释放，确保禁用/重载/退出时按逆序回收。

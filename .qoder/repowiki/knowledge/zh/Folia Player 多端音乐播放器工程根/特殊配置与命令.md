`npm run dev` 启动纯 Web 开发；`npm run dev:electron` 通过环境变量 ELECTRON_DEV=true、FOLIA_WINDOWTOLAYER_PATH、FOLIA_WALLPAPER_HELPER_PATH 并行启动 Vite 与 Electron；`npm run build:electron` 先构建 windowtolayer 与 wallpaper-helper 原生辅助程序再执行 electron-builder；`npm run test` / `test:unit` / `test:ui` 分别运行 Vitest 单元测试与 Playwright UI 截图测试；`npm run stage:client` 单独打开 OBS 源调试页面。

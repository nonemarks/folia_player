本模块由两个并列子目录构成：`docs/` 存放面向人类读者的 Markdown 文档（技术栈、部署、歌词 API、本地库管理、已知问题等），`skills/` 存放面向 AI Agent 的结构化技能定义。每个 skill 采用统一目录结构——顶层 `SKILL.md` 以 YAML front matter 声明 `name` 和 `description`，正文描述任务触发条件、工作流程、命令和边界；部分 skill 在 `agents/openai.yaml` 中提供 `display_name`、`short_description`、`default_prompt` 等元数据供 OpenAI 风格 agent 加载，少数 skill（如 `kugou-provider-alignment`）附带 `scripts/` 下的辅助脚本（PowerShell probe 脚本）。文档之间通过交叉引用相互关联，例如 `technical.md` 作为入口链接到 `lyric-api.md`、`qq-music-deployment.md` 等专题文档；skill 之间也互相引用（如 `codebase-navigation` 引用 `online-song-omni-routing` 和 `glossary-alignment`），形成“文档 + 可执行指引”的双层知识体系。该模块不产出运行时代码，仅作为仓库级约定被根级 README、CI workflow 和 AI 工具链消费。

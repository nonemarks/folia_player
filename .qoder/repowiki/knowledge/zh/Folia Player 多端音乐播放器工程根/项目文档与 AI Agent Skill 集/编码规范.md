- 每个 skill 的 `SKILL.md` 顶部使用 YAML front matter 声明 `name` 与 `description`，并在正文中以标题分节组织触发条件、工作流程、命令和边界说明。
- 需要 agent 配置的 skill 在 `agents/openai.yaml` 中集中维护 `display_name`、`short_description`、`default_prompt`，与业务逻辑分离。
- 文档之间通过相对路径或仓库内绝对路径相互引用（如 `technical.md` 引用 `lyric-api.md`、`qq-music-deployment.md`），避免硬编码外部 URL 以外的链接。
- 对外暴露的接口文档（如 `lyric-api.md`）同时给出 TypeScript 类型定义、HTTP 示例、状态码表和调用示例，保持契约可见性。
- 涉及敏感凭据的 skill（如酷狗对齐）明确禁止将 `.env.local`、`.dev-credentials` 内容写入源码或提交物，并通过脚本参数而非命令行传参传递凭据。
- skill 正文中对仓库路径、命令名、配置文件项的引用需与实际 tracked files 保持一致，变更时需通过 `git ls-files` 等静态核对而非凭记忆编写。

以 `compose.yaml` 为发布版核心编排，定义 gateway（Nginx + 静态前端）、backend（Node.js API）、netease-api/kugou-api/qq-api（各音乐平台代理）和 sync-server（独立同步服务）六个服务；通过三个隔离网络 `folia-edge`（对外暴露 18080）、`folia-internal`（内部互通且 `internal: true` 禁止出网）、`folia-sync`（仅 sync-server 加入）实现最小权限通信边界。`compose.build.yaml` 与 `compose.sync.yaml` 作为叠加覆盖文件，分别将镜像源切换为本地 `../..` 上下文构建以及仅启动 sync-server。每个服务的运行时镜像由 `images/*.Dockerfile` 定义，采用多阶段构建：gateway 使用 `node:24-alpine` 构建 Vite 产物后交由 `nginx:1.29-alpine` 运行，并通过 `entrypoint.sh` 用 `envsubst` 动态生成 Nginx 配置；其他 Node 服务统一基于 `node:24-alpine` 并以 `read_only: true` + `tmpfs /tmp` 运行。环境变量集中通过 `.env.example` 注入，关键凭据如 `SYNC_TOKEN`、`QQ_SESSION_SECRET` 由 Compose 强制校验。健康检查全部通过 `http://127.0.0.1:<port>/healthz` 等端点完成，`scripts/smoke-test.sh` 在本地构建后验证所有公开入口与网络隔离。

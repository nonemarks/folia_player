生产部署只需下载 `compose.yaml` 与 `.env.example` 到空目录，生成 `SYNC_TOKEN=openssl rand -hex 32` 后执行 `docker compose pull && docker compose up -d --wait`；本地开发可通过 `FOLIA_IMAGE_NAMESPACE=folia-local SYNC_TOKEN=docker-check-token docker compose -f deploy/docker/compose.yaml -f deploy/docker/docker/build.yaml build && ./deploy/docker/scripts/smoke-test.sh` 构建并冒烟测试；仅运行 Sync Server 时使用 `docker compose -f deploy/docker/compose.sync.yaml up -d --build`。

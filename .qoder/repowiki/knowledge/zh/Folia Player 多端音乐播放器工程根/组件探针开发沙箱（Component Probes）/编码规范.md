- 每个探针文件导出一个名为 `definition` 的对象并 default export，包含 id、title、description 和 Component 四个字段，严格遵循 `ProbeDefinition` 接口。
- 探针通过 import 真实业务组件并使用 `useState`/`useRef` 维护本地状态来切换不同视觉态（如已安装/未安装、日间/夜间模式），而非复制组件逻辑。
- 当被测组件依赖 Electron IPC 或全局上下文时，探针在模块作用域或 effect 中注入 mock（如 `window.electron.*`、`useThemeQuickEditorStore.getState().setContext(...)`），使组件能在浏览器中独立运行。
- 探针使用 `data-probe-*` 自定义属性（如 `data-probe-action`、`data-probe-daylight`、`data-probe-saved-target`）标注交互元素与状态，便于自动化测试定位。
- 探针通过按钮组合枚举关键 UI 状态（如下载失败态、设备不支持态），并用 key 变化触发子组件重新渲染以刷新状态。

- 启动链采用“index 安装运行时副作用 → 动态 import bootstrap → bootstrap 注册 mod 并挂载根组件”的分阶段初始化模式，确保调试/帧率限制等在 React 渲染前就绪。
- 根组件挂载通过解析 URL 查询参数（`obs`、`obsSource`、`remote`）在多个独立渲染目标（主应用、OBS 三种 source、Remote Control）之间切换，而不是使用路由库。
- Electron 平台能力通过 `vite-env.d.ts` 中的 `declare global { interface Window { electron?: ... } }` 统一扩展，所有调用方以可选属性方式访问，保证浏览器构建下无副作用。
- 跨模块共享领域模型集中在 `types.ts` 中以 TypeScript interface/type 声明，组件与 hooks 仅消费这些类型而不重复定义数据结构。
- 大型编排逻辑集中在 `App.tsx`，但新功能通过拆入 `components/app/*/build*.ts`、`create*.ts`、`hooks`、`stores`、`services` 接入，避免继续复制 JSX 与副作用到该文件。
- 对重型/低频功能（如 `AutomixTransitionAnimation`、`navidromeService`、`whisperAlignService`）使用 `lazy(() => import(...))` 或函数内动态 `import` 进行按需加载，减小首屏 bundle。

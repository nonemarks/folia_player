根目录通过 package.json 的 scripts 将各子模块串联：`vite build` 同时产出桌面主界面（index.html）、OBS 源（stage-client.html）与模组导出页（mod-export.html）三个 HTML 入口；`dev:electron` 用 concurrently 并行启动 Vite 开发服务器与 Electron 主进程，由 electron_host 监听端口 3000 加载前端产物并通过 IPC 暴露窗口、托盘、壁纸模式与外部 API 桥接能力。sync_server 与 api_adapters 提供跨平台（Node/SQLite 与 Cloudflare Workers/D1/Vercel Edge）的同步与 QQ 音乐代理接口，被前端与 Electron 通过统一的 /api/* 路径访问。mod_system 下的模组通过 mod.json 清单向 electron_host 注册命令与可视化模式，运行时由宿主动态加载。packaging 在 `build:electron` 中调用 electron-builder 将 dist、electron、shared、mods 等资源打包为 macOS DMG、Windows NSIS/Portable、Linux tar.gz/deb/rpm。deploy_docker 则基于同一份源码通过 Docker Compose 编排 Nginx 网关、API 适配层、Sync Server 与前端静态资源，实现 Web 端一键部署。tests 使用 Vitest 对前端逻辑与 Playwright 对 UI 进行回归验证，docs_and_skills 提供 AI Agent Skill 规范辅助开发。

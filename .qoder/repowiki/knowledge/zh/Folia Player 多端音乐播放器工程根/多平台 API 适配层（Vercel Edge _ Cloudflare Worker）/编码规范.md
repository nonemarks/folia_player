- 每个业务功能在 `api-ts/`（Vercel Edge）和 `worker/`（Cloudflare）各自维护一份同名 handler，分别适配宿主的 `req/res` 与原生 `Request/Response` 模型。
- 对外暴露的统一路由前缀集中在 `worker/qq.ts` 的 `QQ_API_PREFIX = '/api/qq'`，并通过 `handleQqServerlessRequest` 把宿主差异收敛后再转发给 `qq-music-api` 的 `handleRequest`。
- AI 主题生成统一先截取 lyrics 前 2000 字符再调用 LLM，并对返回 JSON 调用 `sanitizeDualTheme` 清洗后强制写入 `fontStyle='sans'` 与 `provider` 字段。
- 歌词代理采用白名单域名校验（qq.com/.qq.com、kugou.com/.kugou.com、amll-ttml-db.stevexmh.net）+ 固定忽略头列表（host/connection/origin/referer 等）的方式转发请求。
- 所有 handler 对非 POST 请求返回 405，缺失必填参数返回 400，配置缺失返回 500，异常统一 catch 后返回 `{ error }` JSON。
- QQ 扫码通道的对象名通过 HMAC-SHA256(`qr:${qrcodeId}`) 派生，避免使用明文 qrcodeID 作为 DO idFromName 输入，实现纵深防御。

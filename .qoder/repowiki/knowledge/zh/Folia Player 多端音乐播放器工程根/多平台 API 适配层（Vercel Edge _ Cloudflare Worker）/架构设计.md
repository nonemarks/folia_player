模块按宿主环境一分为三：`api/` 是 `api-ts/` 经 tsconfig 编译输出的 JavaScript 产物（`outDir: ../api`），作为 Vercel frameworkless 项目的 Edge Runtime 函数；`worker/index.ts` 是 Cloudflare Worker 的单一入口，通过 pathname 分发到 `generate-theme`、`generate-theme_openai`、`lyric-proxy`、`qq` 四个 handler，并兜底将未匹配请求交给 `ASSETS.fetch` 返回静态资源；`api-ts/` 中的同名 `.ts` 文件是 Vercel 侧源码，`worker/` 中是对应的原生 `Request/Response` 实现。

依赖方向单向向下：各 handler 调用共享逻辑 `../shared/themeSanitizer.mjs` 对 Gemini/OpenAI 返回的双主题 JSON 做清洗，QQ 相关逻辑统一委托第三方包 `@yakult-green-tea/qq-music-api/serverless` 的 `handleRequest`，本模块仅负责把不同宿主的请求路径还原成后端期望的 `/login/status` 等路径（Vercel 通过 `vercel.json` rewrite 注入 `?path=`，Worker 由 `run_worker_first` 直接透传原始 pathname）。QQ 扫码通道以可选 Durable Object binding（`QQ_QR_CHANNEL`）形式注入，通过 HMAC 派生的不可猜 channelName 隔离每个二维码会话，未绑定则优雅降级为仅微信通道。

三个外部服务通过环境变量解耦：Gemini 走 `GEMINI_API_KEY`，OpenAI 兼容走 `OPENAI_API_KEY/URL/MODEL/TEMPERATURE`，QQ 登录走 `QQ_SESSION_SECRET[_PREVIOUS]`。

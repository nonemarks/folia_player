- 所有数据库访问通过 `D1Database.prepare(...).bind(...).first/all/run` 链式调用，避免原生 SQL 拼接，便于在 D1 与 SQLite 之间切换。
- 批量写入使用 `db.batch([...])` 提交多条语句，并在 Node 后端以 `better-sqlite3` 事务包裹以保证原子性。
- 路由通过两个 Hono 实例组织：全局 app 挂载 CORS、token 强度校验与 schema 初始化，子 app `api` 集中处理受 Bearer Token 保护的 REST 接口，最后 `app.route('/', api)` 合并。
- 对外部输入一律进行类型收窄与白名单校验（如 `isRecord`、fingerprint 字符串过滤、bucketId 范围检查、limit 上下界截断），非法请求返回 `{ ok: false, error }` 结构。
- 主题写入采用时间戳幂等策略：`INSERT ... ON CONFLICT ... WHERE excluded.updated_at >= ...`，确保旧版本不会覆盖新记录。
- 环境变量（`SYNC_TOKEN`、`DASHBOARD_TOKEN`）在 Node 入口强制校验存在性与最小长度（≥8），不满足则直接退出进程。

模块以 `src/app.ts` 为核心，使用 Hono 定义全部路由（`/health`、`/state`、`/settings`、`/themes/{manifest,get,put,bucket,list}`）并通过 Bearer Token 中间件保护；所有数据库操作通过 `D1Database` / `D1PreparedStatement` 类型抽象，使同一份路由代码可复用至不同后端。
- 运行时适配层：`src/cloudflare.ts` 直接导出 app 作为 Worker 入口，由 Wrangler 注入 D1 绑定；`src/node.ts` 启动 Node HTTP 服务，用 `@hono/node-server` 承载请求，并构造 `D1Emulator` 将 `better-sqlite3` 暴露为 D1 兼容接口。
- 数据持久化：`src/d1-emulator.ts` 实现 `D1Database`，在 SQLite 上启用 WAL 模式并以事务包装 `batch` 调用；schema（`settings`、`themes`、`theme_buckets` 三表及索引）在首次请求时通过 `ensureSchema` 懒创建。
- 主题分桶设计：固定 256 个 bucket，通过自定义哈希函数对 fingerprint 取模落桶，写入时按 bucket 聚合 `countDelta` 与 XOR 哈希增量，查询 `/themes/manifest` 返回各 bucket 摘要，客户端据此做增量同步。
- 配置与环境：Cloudflare 部署通过 `wrangler.toml` + `wrangler.local.toml` 声明 D1 绑定与 Secret（`SYNC_TOKEN`、`DASHBOARD_TOKEN`）；Node 自托管从 `.env` 读取相同键，端口与 DB 路径可配。
- 依赖方向：`cloudflare.ts` / `node.ts` → `app.ts` ← `d1-emulator.ts`；业务逻辑完全解耦于底层存储。

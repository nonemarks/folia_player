三种部署方式由 `install.sh` / `install.ps1` 脚本统一引导：Cloudflare 流程自动执行 `wrangler d1 create`、生成 `wrangler.local.toml`、`wrangler secret put SYNC_TOKEN/DASHBOARD_TOKEN` 并 `npm run deploy:cf`；Docker 通过仓库根目录 `deploy/docker/compose.sync.yaml` 启动；Node 自托管需先创建 `.env`（含 `SYNC_TOKEN`、可选 `DASHBOARD_TOKEN`、`PORT`、`DB_PATH`），再执行 `npm run start:node`（开发热重载用 `npm run dev:node`）。

- 平台特定构建通过 Node 脚本的 `process.platform` 守卫实现：非目标平台直接打印日志并 `process.exit(0)`，保证跨平台 CI 不依赖本机工具链。
- Rust 源码使用 `#[cfg(windows)]` 对模块与函数进行 target-gated 编译，使同一 crate 可在 Linux/macOS 上执行 `cargo test` 而不需要 Windows SDK。
- 第三方二进制依赖采用“固定上游修订 + 本地补丁”模式：修订号集中声明在构建脚本常量中，补丁文件置于 `packaging/linux/patches/`，并通过 `git apply` 以幂等方式应用。
- 构建产物统一输出到仓库根 `build/` 目录，由 electron-builder 的 extraResources 机制打包进最终发行版，避免将中间产物提交到版本库。
- AUR 包维护通过 `update.sh` 自动从 `package.json` 读取版本号并重新计算 `.desktop`/`.png` 的 sha256sum，保持 PKGBUILD 与 .SRCINFO 同步。

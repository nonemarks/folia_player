本模块按目标平台划分为三个子目录：
- `aur/folia-major-bin/`：AUR 二进制包定义，包含 `PKGBUILD`（从 GitHub Release 拉取预编译 tar.gz 并安装到 `/opt/folia-major`）、`.SRCINFO`、桌面入口 `folia-major.desktop` 与图标，并提供 `update.sh` 自动同步版本号与 sha256sum。
- `linux/`：通过 Node.js 脚本 `build-windowtolayer.mjs` 在构建时从 GitLab 拉取固定修订的 `windowtolayer` 源码，应用 `patches/` 下的两个补丁（popup 容错与仅主窗口作为壁纸层），用 `cargo build --release` 编译并将二进制与 GPL-3.0 COPYING 复制到根 `build/`，供 electron-builder 作为 extraResources 打包；非 Linux 主机直接跳过。
- `windows/wallpaper-helper/`：一个独立的 Rust crate（`Cargo.toml` 使用 `cfg(windows)` target-gated 依赖 `windows` crate），实现 WorkerW 父窗口挂载、消息循环、显示器监控与 Raw Input 鼠标转发，通过 JSONL 事件与 Electron 主进程通信；由 `build-wallpaper-helper.mjs` 在 Windows 上调用 `cargo build --release` 产出 `folia-wallpaper-helper.exe` 放入 `build/`。
依赖方向：Node 构建脚本 → 外部工具（git/cargo）→ 产物进入根 `build/`；Rust 辅助程序仅通过标准输入输出与 Electron 主进程交互，不反向依赖打包脚本。

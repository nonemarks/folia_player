### Realeco
- 定义：Folia 的正式版发布通道，仅在 main 分支修改根目录 realeco-release 文件时触发自动构建，客户端通过 latest 通道获取更新。
- 别名：正式版通道

### Limo
- 定义：Folia 的 Nightly 构建通道，对应 beta 预发布流，可从 Realeco 升级。
- 别名：Nightly 通道

### Cielo
- 定义：Folia 的 Canary 预发布通道，对应 alpha 流，也可升级到 Limo/Realeco；其 [canary] 推送会更新滚动 prerelease。
- 别名：Canary 通道

### Mod 系统
- 定义：Folia 的扩展机制，位于 mods/ 目录，每个模组包含 mod.json 清单与 index.cjs 实现，通过 commands.register + permissions 声明能力；采用 fail-closed 策略，新模组需经原生信任对话框确认内容指纹后才启用。
- 别名：mods、模组系统

### 设置页子视图（SettingsSubview）
- 定义：设置中心 UI 的分层结构：SettingsModal 顶层弹窗下挂多个子视图（Playback/Appearance/Integration 等），每个子视图可再打开独立子弹窗（如 LyricFilter/GlobalLyricOffset/Whisper），通过 useSettingsUiStore.ts 中的 SettingsSubviewId 管理导航。
- 别名：SettingsSubview、子视图

### Whisper 设置页
- 定义：从 PlaybackSettings 内联 toggle 迁移出的独立弹窗（WhisperSettingsModal.tsx），包含 Whisper 开关、环境检查（WhisperEnvCheck）与模型选择器，通过 Sparkles+ChevronRight 按钮从设置页导航进入。
- 别名：WhisperSettingsModal、Whisper 设置

### Whisper 统一 API 层
- 定义：whisperModService.ts 提供的抽象层，优先调用已启用的 mod 命令（check-status/list-models/download-model/transcribe 等），若 mod 未启用则回退到直接 IPC 调用底层 whisperAlignService，使前端组件无需感知后端实现方式。
- 别名：whisperModService、统一 API

### 行内对齐按钮（WhisperAlignButton）
- 定义：歌词面板中的行内触发按钮，点击直接执行 Whisper 对齐并显示进度条，出现在 NaviTab/LocalTab/OnlineLyricsTab 等歌词面板中；待改造为打开 Whisper 设置页的入口。
- 别名：WhisperAlignButton、行内对齐按钮

### Stage API
- 定义：Folia 提供的从外部程序与播放器深度交互的接口，可通过 npm run stage:client 启动本地联调台进行调试。
- 别名：stage-client

### 歌词接口
- 定义：Electron 桌面端可在“连接与集成”中启用的本地 HTTP 服务，仅在 127.0.0.1:32109/v1/lyric 提供无需鉴权的精简歌词 JSON，并在顶层 offset 字段携带用户设置的歌词时间偏移（毫秒）。
- 别名：lyric API、v1/lyric

### Sync Server
- 定义：Folia 官方可选同步服务端，用于在多设备间同步外观设置与 AI 主题库，支持 Cloudflare Workers/D1、Docker、Node.js 自托管三种部署方式，客户端通过 SYNC_TOKEN 认证。
- 别名：sync-server、同步服务

### 窗口层级工具（windowtolayer）
- 定义：Linux 壁纸模式依赖的原生二进制工具，由 packaging/linux/build-windowtolayer.mjs 构建，首次联调前需执行 npm run build:windowtolayer；缺失时壁纸模式自动回退关闭。
- 别名：windowtolayer

### 壁纸助手（folia-wallpaper-helper.exe）
- 定义：Windows 壁纸模式依赖的辅助程序，由 packaging/windows/build-wallpaper-helper.mjs 构建，随安装包分发至 build/folia-wallpaper-helper.exe。
- 别名：wallpaper-helper

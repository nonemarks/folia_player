## 简介
Folia 是一款以全屏沉浸式歌词播放为核心的在线音乐播放器，支持网易云、酷狗、QQ 音乐和本地音乐库，提供智能歌词匹配、AI 生成主题和多种全屏歌词动画。项目同时提供 Electron 桌面端与基于 Node.js 的 Web 版本，并支持 Docker 容器化部署。

本快速开始指南面向新用户，目标是帮助你在最短时间内完成下载、安装、基础配置并成功运行 Folia，体验核心功能。

## 环境要求
- Node.js：建议使用 Node.js 24 或更高版本（用于本地开发与构建）。
- 浏览器：推荐使用现代 Chromium 内核浏览器；若需完整本地音乐导入能力，请使用支持 File System Access API 的桌面端 Chromium 系浏览器。
- Docker：如需容器化部署，需要 Docker Engine 24+ 与 Docker Compose v2。
- HTTPS：生产环境强烈建议通过反向代理终止 HTTPS，以获得浏览器安全上下文，启用 Service Worker、PWA、OPFS、音频设备枚举等能力。

## 桌面版安装与首次运行
桌面版内置前后端运行环境，适合即装即用。

- 获取安装包：前往 Releases 页面下载 Windows、macOS 或 Linux 安装包。
- 安装与启动：按系统提示安装后直接启动应用即可。
- 首次体验：
  - 使用在线音源：在设置中配置所需音源后端地址，例如网易云 API 地址。
  - 使用本地音乐：导入本地音乐文件夹，扫描完成后即可浏览海报墙并播放。
  - 同步外观设置：可选部署 Sync Server，并在设置中填写服务端地址与 Token 实现跨设备同步。

注意事项
- 桌面版已内置 QQ 音乐服务，无需额外部署。
- 若遇到 Wayland/Hyprland 遥控窗或 Linux 包相关问题，可参考技术说明中的平台细节。

## Web 版本地开发
如果你希望以开发者方式运行 Web 版，推荐在本地使用 Vite 或 vercel dev。

步骤概览
1. 安装依赖：在项目根目录执行依赖安装命令。
2. 创建环境变量文件：复制模板为 `.env.local`，并按需填写变量。
3. 启动开发服务器：使用推荐的开发命令启动本地服务。
4. 访问应用：默认监听端口为 3000，可在浏览器打开本地地址进行调试。

重要说明
- 网易云 API 地址必须配置，否则在线搜索与播放会失败。
- 若同时验收多个服务，请调整各服务端口避免冲突。
- 修改环境变量后需重启开发服务器。

## Web 版一键部署到 Vercel / Cloudflare
如果你希望快速上线 Web 版，可使用一键部署入口创建项目，并在平台设置中补齐环境变量。

Vercel
- 使用一键部署按钮克隆仓库并创建项目。
- 在环境变量中配置 QQ 音乐 serverless 入口与密钥。
- 重新部署使环境变量生效。

Cloudflare
- 使用一键部署入口创建 Worker。
- 如需 QQ 扫码登录，需在 Wrangler 配置中绑定 Durable Object。
- 部署后检查 `/api/qq/login/channels` 返回的通道列表是否符合预期。

注意
- `VITE_QQ_API_BASE` 是构建时变量，修改后必须重新构建并部署。
- `QQ_SESSION_SECRET` 应保存在平台 Secret 中，不要写入前端资源。

## Docker Compose 全栈部署
Docker 部署提供完整的 Web 堆栈：前端网关、Folia Web API、在线音乐接口以及独立的 Sync Server。对外仅暴露 Web 网关与 Sync Server 端口，其余服务通过 Docker 网络互访。

快速启动
1. 新建空目录并下载 compose.yaml 与环境变量模板。
2. 生成 Sync Token 并填入 `.env`。
3. 验证配置并启动服务。
4. 访问默认地址：Web 网关与 Sync Server。

健康检查
- Gateway：`/healthz`、`/api/healthz`、`/runtime-config.js`、`/netease/`、`/kugou/`、`/qq/login/status`。
- Sync Server：`/health`。

HTTPS 与安全上下文
- HTTP 下部分能力不可用或降级，包括本地音乐目录导入、Service Worker/PWA、OPFS、音频设备枚举等。
- 推荐通过 NAS 反向代理终止 HTTPS，并正确传递 Host、X-Forwarded-Host、X-Forwarded-Proto、X-Forwarded-For。
- 证书链必须可信；不支持将应用挂载在 `/folia/` 子路径。

更新与维护
- 更新镜像后重新拉起服务。
- 回滚时固定版本号再重复拉取与启动流程。
- 备份 Sync Server 数据目录。

## 环境变量与关键配置
以下表格汇总了本地开发、Web 部署与 Docker 部署中最常用的环境变量。不同环境下的变量命名与注入方式可能不同，请根据实际部署方式选择对应配置。

| 变量名 | 用途 | 是否必需 | 备注 |
| --- | --- | --- | --- |
| `VITE_NETEASE_API_BASE` | 网易云音乐 API 实例地址 | 是 | Web 版必须配置 |
| `VITE_KUGOU_API_BASE` | Web 版酷狗 API 实例地址 | 否 | Electron 不使用此项 |
| `VITE_QQ_API_BASE` | QQ 音乐 API 实例地址 | 否 | Vercel/Cloudflare 可填 `/api/qq` |
| `QQ_SESSION_SECRET` | serverless 形态加密登录态密钥 | 用 `/api/qq` 时需要 | 不加 `VITE_` 前缀 |
| `QQ_SESSION_SECRET_PREVIOUS` | 轮换密钥时验证旧令牌 | 否 | 避免全员登出 |
| `VITE_AI_PROVIDER` | AI 提供商 | 是 | `google` 或 `openai` |
| `GEMINI_API_KEY` | Gemini API Key | 使用 Gemini 时需要 | 仅传给后端 |
| `OPENAI_API_KEY` | OpenAI 兼容 API Key | 使用 OpenAI 兼容接口时需要 | 仅传给后端 |
| `OPENAI_API_URL` | OpenAI 兼容接口地址 | 使用 OpenAI 兼容接口时需要 | 可为 base URL 或完整地址 |
| `OPENAI_API_MODEL` | 模型名 | 使用 OpenAI 兼容接口时需要 | 例如 gpt-4o |
| `OPENAI_API_TEMPERATURE` | 温度 | 否 | 默认 0.7 |
| `SYNC_TOKEN` | Sync 客户端 Bearer Token | Docker 部署必填 | 至少八位 |
| `FOLIA_HTTP_PORT` | Web 网关端口 | Docker 部署常用 | 默认 18080 |
| `FOLIA_SYNC_PORT` | Sync Server 端口 | Docker 部署常用 | 默认 13000 |

注意
- 部分变量仅在特定部署方式下生效，例如 `VITE_*` 为构建期变量，`QQ_SESSION_SECRET` 不应出现在前端资源中。
- Docker 环境中 AI 密钥只传给 backend 容器，不会写入前端静态文件。

## 常见部署场景示例

  3. 启动开发服务器。
  4. 访问本地地址进行调试。

  - 若同时运行网易云 API 与 QQ API，需调整端口避免冲突。

## 故障排除与常见问题
### 在线搜索或播放失败
- 检查是否已配置网易云 API 地址。
- 检查后端服务是否可达与健康检查是否通过。
- 若使用 Docker，确认 gateway 依赖的服务均已健康。

### QQ 音乐登录异常
- 现象：页面显示登录错误、返回 HTML 而非 JSON、或只有微信扫码。
- 排查：
  - 检查 `/api/qq/login/channels` 是否返回 JSON。
  - 检查 `QQ_SESSION_SECRET` 是否设置并重新部署。
  - Vercel 仅支持微信扫码；Cloudflare 需启用 Durable Object 才支持 QQ 扫码。
  - 修改 `VITE_QQ_API_BASE` 后需重新构建。

### 本地音乐导入不可用
- 原因：浏览器不支持 File System Access API 或处于 HTTP 不安全上下文。
- 解决：
  - 改用支持目录选择的浏览器或桌面版。
  - 使用 HTTPS 并配置可信证书。
  - 重启后若权限丢失，按界面提示恢复目录访问权限。
